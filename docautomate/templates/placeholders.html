Полета за бланките

Пишете тези полета в Word бланката. При генериране всяко поле се заменя с данните на случая. Кликнете поле, за да го копирате.

Как се пише

  • Стойност: {{ '{{ candidate.name_cyr }}' }}
  • Според пола: {{ '{{ candidate.roden }}' }} дава „роден“ или „родена“. Или: {{ "{% if candidate.female %}г-жа{% else %}г-н{% endif %}" }}
  • Само при удължаване: {{ "{% if case.is_extension %}…текст…{% endif %}" }}
  • Списък (напр. задължения в ДХ) – три отделни реда в Word, всеки на свой ред:
    {{ '{%p for x in position.dh_duties %}' }}
    {{ '{{ x }}' }} ← форматирайте този ред като номериран списък
    {{ '{%p endfor %}' }}
  • Абзаци на обосновката: същото с position.obosnovka_paragraphs. По-просто: {{ '{{ position.obosnovka }}' }} (всички абзаци в един, с нови редове).
  • Празно поле излиза като „……………………“ за попълване на ръка.
